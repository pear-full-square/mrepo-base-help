# mrepo/

The howto protocol's part of an mrepo's structure: the howto layer.

- **The `howto` layer** (`howto/layer.json`): where `howto/extract`
  writes the linked packages' how-tos: `index.json`, the how-tos by
  activity; `<activity>/<name>.json`, one how-to with its steps;
  `problems.json`, the how-tos against their form. Empty until the
  first extraction.
